# Terminology
This document contains definitions of technical terms encountered while building the Active Directory and SIEM homelab.

## Active Directory
| Term | Description |
|---|---|
| Active Directory (AD) | Microsoft's directory service for managing users, computers, groups, and access within a Windows domain |
| Domain Controller (DC) | Server that handles domain authentication and provides Active Directory services |

## SIEM
| Term | Description |
|---|---|
| SIEM | Security Information and Event Management; platform that collects and analyzes security data to help identify suspicious activity |
| Splunk | platform used to search, analyze, and visualize machine-generated data, including security logs  |
| Sysmon | A Windows system service and driver that records detailed system activity in event logs |
| Splunk Universal Forwarder | A lightweight agent that collects data from a machine and forwards it to a Splunk instance |

## Others
| Term | Description |
|---|---|
| Atomic Red Team | An open-source library of small, focused tests mapped to MITRE ATT&CK techniques |
| MITRE ATT&CK | knowledge base that contains tactics & techniques commonly used by adversaries  |
