# active-directory-homelab

This project focuses on building an isolated Active Directory environment to explore Windows domain administration, security monitoring, and threat detection.

Using VirtualBox, the lab integrates Windows Server, Windows 10, Ubuntu Server running Splunk, and Kali Linux to simulate a small enterprise network. It covers Active Directory configuration, centralized log collection, security event monitoring, controlled attack simulations, and detection analysis.

This repository documents the lab setup, configurations, practical exercises, troubleshooting, and technical knowledge gained throughout the project.

**Main Technologies:** VirtualBox, Windows Server, Windows 10, Active Directory, Ubuntu Server, Splunk, Sysmon, Kali Linux, and Atomic Red Team.

This project is based on the Active Directory Home Lab tutorial series by MYDFIR.

Special thanks to MYDFIR for providing the learning resources and practical guidance used throughout this project. The lab implementation and documentation are maintained independently, with additional notes, troubleshooting, and observations recorded along the way.
